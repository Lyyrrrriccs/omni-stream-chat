How to Install & Activate a Pack

  1. Download any .json pack file above (or test every pack live in the Interactive Preview — including the animated League Client Scene Frame).
  2. In OmniGrid Studio, open 🎮 Game Addons and click 📥 Import Pack (.json) under Overlay Design Pack.
  3. Select your preferred pack in the dropdown anytime — all 16 OBS overlays AND the animated 1920×1080 League Client Frame (/lol-bg) update live.
